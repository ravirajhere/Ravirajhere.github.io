## Local Development

No build step. Just open any HTML file in a browser.

For best results, run a local server:

    python -m http.server 8000

Then open: http://localhost:8000

---

## Deploy

Hosted on **GitHub Pages**. Push to `main` branch — site updates automatically.

    git add .
    git commit -m "Update"
    git push origin main
